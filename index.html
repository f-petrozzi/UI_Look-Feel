What is EduInsight?

EduInsight is a static prototype for an academic analytics app. Its purpose is to help programs quickly understand enrollment patterns and student performance by summarizing key metrics on the Home page, visualizing trends on the Data visualization page, and organizing project context on the About page.

Key features include interactive charts powered by Chart.js (see charts), simulated CRUD navigation to demonstrate how records would be created, viewed, updated, and deleted (buttons below), and an integrated Botpress assistant for dataset Q&A (Ask EduBot).
